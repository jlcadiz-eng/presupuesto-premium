🚫 Excepciones inversas — Tipo A/B tratados como C/D 6 clientes ▶

Esta lista tiene prioridad sobre todo lo demás: si un cliente está aquí, siempre se reclama, aunque también esté en la lista A/B o en excepciones.

Cómo funciona: las listas de clientes Tipo A/B, de excepciones aprobadas para C/D y de excepciones inversas ya vienen cargadas — cualquier cliente que no esté en ninguna se trata como Tipo C/D estándar (caducidad de 14 días, hay que reclamar). La lista de excepciones inversas tiene prioridad sobre las demás: un cliente A/B marcado ahí siempre se reclama, por circunstancias comerciales. Edita las tres listas arriba cuando cambie una clasificación, se apruebe una nueva excepción o quieras forzar condiciones más estrictas a un cliente concreto; los cambios se guardan en este navegador para la próxima vez que abras la herramienta. Solo hace falta subir el export de pedidos para procesar. Nada se envía a ningún servidor: todo el cálculo se hace en tu navegador.
